Room events resolve persisted rows through the captured radio/session key rather
than rendering an unpartitioned event payload. Removing a default known region
first verifies that the radio's flood scope is cleared, then persists and reads
back the local region change. Restore uses the store's own IO dispatch so a
dispatcher-return cancellation cannot discard a committed receipt. Startup
failure while replaying pending actions also closes the initialized graph.
Foreground hosting follows the live link's transport even when a device retains
both Wi-Fi and Bluetooth methods; the existing Wi-Fi-only saved-method rule is
used only before a live transport exists. Presence power checks reuse the guarded
BLE capability reader, so revoked connect permission cannot trigger an
unguarded adapter access or prevent a Wi-Fi-only host from reporting its facts.

The original iOS release-specific What's New announcement is not presented as an
Android release announcement. The full categorized/searchable emoji picker is now
bound to both composer insertion and message reactions, in addition to the native
input method. It preserves the source's eight-category order, label/shortcode/tag
search, 20-entry frequent MRU and six reaction shortcuts. Reaction selection removes
the child picker before dispatching through the current radio and dismissing the
parent actions sheet. No translation provider/model or runtime dataset download is
introduced.

The frozen `project.yml` declares `emojibase-bindings` from 1.5.0. Android locks the
complete bundled iOS resource at that declared version, Git commit
`d1ed54c3bf63caa8fb48a30e16e465ac148f26f6`, rather than silently taking a newer
catalog or inventing a small replacement. `platforms/ios/Emojibase/Resources/emojibase.json`
is retained byte-for-byte (624,991 bytes, 1,932 records, SHA256
`b69315f939d4a2c4332e09b70c8278e0a9e0e7465d98c71f95e50b7ad76a4cfb`).
The bindings' Apache-2.0 notice and Emojibase Data 17.0.0's MIT notice are packaged
and discoverable in the license screen. The latter is from commit
`a5fc630a91ca42cddf3f4a66492965600fd3bce8` (the annotated release tag resolves to
this commit). Unicode License V3 was acquired from `https://www.unicode.org/license.txt`;
its exact downloaded bytes are pinned by `emoji_convert.py`, not fetched by builds.
This is notice preservation, not a claim of human legal approval.

`python tools/android-port/emoji_convert.py --source-dir <verified-input-directory>`
copies only exact checksum-bound source inputs. `--check`, also a pre-build task,
fails on a missing/changed catalog or notice and positively checks all category
counts. Frequent emojis use the existing backup-compatible UTF-8 JSON binary
preference. The synchronous feature seam enqueues complete cumulative desired lists
on a process-owned writer; it does not claim a synchronous disk commit. Saved state
is published only after DataStore's persisted result is checked. A failed selection
remains pending, surfaces an inline error/retry, and does not disable messaging.
Refreshing a picker cannot replace a newer pending/saved selection with a stale
read. Resource-local Git attributes prevent checkout newline conversion of the four
checksum-bound inputs; a real `core.autocrlf=true` temporary Git checkout regression
verifies their exact bytes. The reaction regression drives both the service and
Compose schedulers: a real delivered response, persisted recent reaction and
child/parent dismissal are asserted, not just insertion of a pending row.

Message paths now receive the current radio-partitioned device's actual key/name/id
and valid coordinate. Authorized, already requested phone fixes are preferred for
hop resolution with the radio coordinate as fallback; no GPS request occurs during
composition and a different radio's device never supplies an endpoint. App-owned
device edit notifications refresh the path/composer without creating another
connection owner. No arrival invents a path/distance. QR retry explicitly resets a
failed camera when permission is granted; old analyzers/providers/executors dispose
before remounting, and repeated/manual frames share a once-only decode guard.

Two Android-native labels ("System language" and "Open-source licenses") use English
fallback because the frozen Apple catalog has no matching platform labels. Existing
app localization is preserved; these labels do not change the frozen catalog.

Automatic backup/cloud/device transfer remains disabled. Explicit backup uses the
existing WP-203 envelope/codec/atomic restore, not a new format. App adapter tests
are not new bidirectional iOS/Android codec evidence.
