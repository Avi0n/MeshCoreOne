owned parity directory. The frozen source's positive first-accept, peer-close
callback and received-stream completion observations each retain an executable
two-second deadline; the fifteen-second outer watchdog is not their substitute.

reads feed the real parser and filtered dispatcher with literal wire bytes:
valid battery/ACK responses, short/unknown/empty packets and unknown/missing
firmware error codes remain observable in order before clean FIN completes the
streams. Partial delimiter/length/payload EOF cases preserve preceding complete
