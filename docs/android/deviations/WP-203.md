## Explicit native safety and storage boundaries

Record-at-a-time UTF-8 JSON decode and bounded raw-DEFLATE input enforce
50MiB compressed and 512MiB expanded caps before copying overflow bytes.
Numbers retain source signed/unsigned widths, raw values, base64 bytes and
canonical UUID text. Unix fractions normalize to seconds plus nanoseconds,
including negative fractions; native `Instant` representability failures
are typed, never default dates or rewritten UUID version/variant bits.

Unambiguous missing parents retain the source counted-skip policy. Envelope
v1 cannot represent repeats/room messages when a native store has the same
parent UUID on different radios; those identities fail explicitly rather
than cross-link children, drop rows or invent envelope v2. Duplicate JSON
keys and trailing/concatenated compressed streams also fail explicitly:
no backup emitted by the frozen source needs them. Unknown object fields
are decoded structurally and ignored as Codable does; unknown raw enum
cases are not silently mapped to a default. Raw string flood-scope values
remain raw even when their current accessor resolves to inherit.

The database commits before its small non-cancellable, write-if-missing
DataStore operation. A real storage failure afterward exposes
`CommittedBackupPreferenceException` with the committed result, snapshot
and original typed storage failure. Recovery retries only preference
completion, not the database. Malformed present preference bytes fail as
typed corrupt-preference export, rather than silently disappear from the
backup. Underlying paths, aliases, values and keys are not placed in generic
error descriptions/logs. Keystore files and keys are never recreated.
