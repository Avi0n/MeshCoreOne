Reference: `db14559b39d32322b06477c6ae676112f583db50`. Integrated base:
`f34f68d0416da113c2cd0d274c44937f6c41a5d3` (`origin/main`). Owner:

## Native adaptations

- **D-1 Compose action surface.** Swift menus and sheets are represented by a retained state holder and an
  adaptive Compose content surface. Compact layouts show one scrollable detail pane; widths of 600 dp or
  more place the selected path map beside the details. Action execution stays callback-driven so the
  existing timeline/composer owners retain reply, copy, resend, reaction, and delete behavior.
  The successor removes the active Translate button under the approved translation scope removal;
  the inert enum remains for consumer compatibility, not as a reachable action or deferred feature.
- **D-2 Shared-map rendering.** Path details consume WP-312's `MapLibreMapSurface`, OpenFreeMap catalog,
  marker/line algebra, camera calculation, and visible provider attribution. WP-309 adds no provider,
  account, key, Google service, location permission, offline claim, or alternate map behavior.
- **D-3 Durable-data boundary.** `MessageActionsDataSource` is the feature-owned adapter for process
  contacts/discovered nodes, repeat/reaction records, and block/mute writes. The state holder never owns a
  radio session. Feature-local name confidence, reaction-summary, and SNR presentation types avoid a
  forbidden concrete `feature:chats` to `core:services` edge. Cancellation propagates; read, block, and
  mute failures remain typed UI state rather than becoming empty success.
- **D-4 Path resolution.** Stable endpoint/hop IDs are derived from identity bytes, not list positions.
  Ambiguous short hashes remain fallback matches and cannot be drawn as exact located hops. Duplicate
  located hops are rendered once while preserving the original arrival order and completeness result.
- **D-5 Delivery accessibility.** Delivery state is exposed as a textual enum and Compose labels include
  status, SNR quality/value, repeats, path availability, and selectable reaction counts. Color remains
  supplementary. Deterministic JVM tests cover these contracts; physical TalkBack, screenshots, and device
  rendering are not claimed.
- **D-6 Preview adaptation.** Shared-map camera/canvas state replaces Swift snapshot image storage inside
  this feature. Width bucketing and stable preview keys are preserved, while snapshot download/cache
  ownership stays with WP-312. No network-backed preview success is manufactured.

## Deliberate boundaries

The manifest owns the `actions/` implementation and test packages. Existing WP-307 timeline and WP-310
room/channel files are preserved unchanged; they consume the public action/state callbacks when assembled
by their screen owner. No feature-to-feature dependency, second persistence store, radio lifecycle, new
permission, or replacement MapLibre/OpenFreeMap path was introduced.

## Bounded shared-action repair successor

Base: `0a7a84e388393557e4b66ac7fd322248e28611fd`; source pin unchanged.

- **D-7 Reaction presentation.** Frozen `ReactionDetailsSheet` separates a pending read from a successful
  empty read and displays both the empty-state title and description. The successor restores these
  distinctions. Unlike Swift's diagnostic-only catch followed by empty content, Android retains an
  explicit localized load failure and real retry against the same message/preferred emoji. Cancellation
  propagates without becoming a load failure or successful empty read; a retry control remains.
  New requests cancel/supersede prior reads, so old results cannot replace a new selection.
- **D-8 Sender times and layout.** Reuse the shared `TimestampFormatting.relativeComponent` calendar/zone
  calculation with native ICU long/named relative text (including yesterday/tomorrow), rather than the
  contact advert formatter's numeric/old-date policy. Locale comes from current Compose resources;
  an optional injected clock defaults to the real system display zone. Minute refresh is presentation-only.
  A stable-ID `LazyColumn` preserves service order and stacks sender/time instead of squeezing a large-font
  horizontal row. Existing action callbacks and required route arguments remain unchanged.
- **D-9 Test host.** Mounted public-route regressions live in the existing App test harness through an
  automatically admitted `app-build-launcher` support path. No build/dependency/lock changes or second UI
  renderer were added. They are source candidates, not passing native evidence until actually executed.
- **B-1 Mention picker ownership.** `MentionPickerSheet` is actually in WP-308's
  `composer/ui/MentionSuggestions.kt`, not WP-309's `actions/`. Trusted
  `shared-mention-picker-repair` currently admits WP-502 only; actual WP-309 admission failed.
  No picker, Rooms/channel consumer, App location policy or shared contact row was modified.
  The coordinator needs to transfer the repair to an admitted producer or land a trusted capability
  amendment for this producer before that requested omission can be repaired. This is an unresolved
  requested dependency, not an exclusion or completed parity.
