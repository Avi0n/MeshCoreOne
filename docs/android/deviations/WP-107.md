## Historical implementation record

Independent review of ce93/0394 subsequently found eight concrete defects.
The pre-repair normal both-host run37212608599 at0a94e138 reproduced them
with22 actual failed regressions. Historical counts below describe that
historical candidate, not final repair acceptance. The repairs keep normal
generation work structured under its owner but retain teardown separately
so owning-job cancellation cannot cancel the physical close receipt. An
arbitrary unresolved matcher blocks all new exchanges, and contact/binary
possibly-written sends preserve both response and untagged-error uncertainty.
Cache completeness/cursors commit only from a validated current fetch;
incomplete/unsolicited endings cannot advance synchronization. Rollback uses
a bounded bare-OK matcher when old errors are ambiguous, preserving the
original failure/quarantine. Physical ownership survives failed logical
restart attempts. Constructor input validation precedes every parented job.
Fresh deterministic positive and full protocol/root proof is required for
these changes; no static review or prior green artifacts are reused as proof.
