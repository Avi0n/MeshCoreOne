## Actual persistence/consumer boundary and adaptations

The fixture uses API31 Robolectric **native SQLite**, actual file-backed
Room/MeshCoreDatabase and production RoomPersistenceStore. It uses no
in-memory database superclass, fake repository or test-written conversion.
Each store has the test's owned backgroundScope, one injected fixed
java.time.Clock at Unix1704067200, and explicit close in finally before
its Room database closes. The source's incidental current time is not an
asserted input; source radio UUIDs remain fresh.

After the first Room store/database close, a separate Android SQLiteDatabase
opens the same existing file READWRITE. It sets and reads back the source
5000ms busy timeout, performs the literal negative UPDATE and requires one
SELECT row whose string is `"-1"`. Cursor/database `use` scopes close before
constructing the second Room/store instance. Android's SQLiteDatabase owns
the connection/thread-safety policy rather than exposing sqlite3 FULLMUTEX;
the fixture has no concurrent raw SQL operation. Native table/column names
replace private SwiftData `Z...` names; native fixture journal mode is
TRUNCATE, following the existing file-reopen tests, not SwiftData WAL parity.

The public actual service calls `withBackupSnapshot`, real
`MeshCoreDatabase.backupEnvelope`, backupAll DAO queries and production
ContactEntity/DiscoveredNodeEntity.toDTO. Their signed SQL path values must
reach the actual export as UByte255; returning only a repository row or
omitting the row cannot pass. Actual MeshCoreStorage backup preferences are
used and closed, not a fake preference snapshot. Supplementary service
export/parse exercises native serialization of those normalized DTOs.
No candidate output is used to derive an expected packet/field.

The fixture deletes only its named database/SQLite sidecars after all
connections close. Robolectric already gives each method a separate fresh
application directory; `int8.db` is unique within that isolated directory.
No production database name or persistent user data is touched.
